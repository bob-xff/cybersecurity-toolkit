检查项明细

评估依据：《网络安全法》（2025 修正）、《数据安全法》、《个人信息保护法》、GB/T 22239-2019（等保 2.0）、GB/T 35273-2020、GB/T 43698-2024 等国内标准，以及 OWASP Top 10:2021 / ASVS 5.0、ISO/IEC 27001:2022、CIS v8.1、PCI DSS v4.0.1、RFC 系列。

工具仅通过公开渠道做被动 / 低强度探测（读取公开页面与响应头、查询公开 DNS、少量公开路径探测），不注入、不爆破、不触碰内网。完整标准清单见 docs/网站网络安全评估标准清单.md。
