## 一、编制目的与适用范围

本清单依据现行有效的中国法律法规、国家标准（GB/T）及国际主流安全标准整理，形成一套**可落地、可评分、可追溯**的网站安全评判依据，用于：

1. 作为企业网站安全评估的统一度量衡（评估项 → 评分 → 合规等级 → 整改建议）；
2. 作为等保测评、渗透测试、安全运维之外的外部暴露面常态化自查基线；
3. 作为对外投标、供应商安全审查、内部安全考核的评判参考。

**评估性质说明**：本清单驱动的自动化评估属于「外部被动/低强度探测」评估——仅抓取公开页面、读取响应头、查询公开 DNS 记录、少量公开路径探测，**不执行攻击载荷、不暴力破解、不深入内网**。其结论为「网站外部暴露面安全态势」，不等同于等级保护测评结论，也不能替代授权渗透测试。

## 三、评估框架设计

### 3.1 评估维度与权重

| 维度代码 | 维度名称 | 权重 | 覆盖内容 |
|---|---|---|---|
| T | 传输与加密安全 | 25% | HTTPS、TLS 协议与套件、证书、混合内容 |
| H | 安全响应头 | 20% | CSP、HSTS、点击劫持防护、Referrer-Policy 等 |
| D | 内容与代码安全 | 15% | CSRF、前端组件漏洞、SRI、敏感注释、CMS 指纹 |
| E | 信息泄露与暴露面 | 15% | 版本泄露、敏感文件、目录列表、security.txt、错误页 |
| C | Cookie 安全 | 10% | Secure / HttpOnly / SameSite / 前缀 |
| N | DNS 与邮件安全 | 10% | SPF、DMARC、DNSSEC、CAA、MX |
| P | 隐私与合规标识 | 5% | ICP 备案、隐私政策、Cookie 同意 |

### 3.2 评分规则

- 单项状态：**通过 = 1 分，警告 = 0.5 分，不通过 = 0 分，不适用/无法检测 = 不计入，提示级 = 不计入（仅展示）**。
- 单项权重：高危 3、中危 2、低危 1。
- 维度得分 = Σ(单项权重 × 状态分) ÷ Σ(单项权重)（剔除不适用项）。
- 综合得分 = Σ(维度得分 × 维度权重)，取值 0–100。

### 3.3 合规等级判定

| 等级 | 综合分 | 含义 | 处置要求 |
|---|---|---|---|
| **A（优秀）** | ≥ 90 | 外部暴露面防护完善，主要标准项全部达标 | 保持，纳入常态化监测 |
| **B（良好）** | 75–89 | 整体达标，存在少量中低风险缺口 | 30 日内完成中危整改 |
| **C（合格）** | 60–74 | 基本可用，存在明显安全缺口 | 14 日内整改高危项 |
| **D（高风险）** | 40–59 | 多项关键控制缺失，易被利用 | 7 日内整改，整改前加强监控 |
| **E（严重）** | < 40 | 关键基础设施性缺失（如无 HTTPS） | 立即整改，必要时下线风险功能 |

> **与等保的参考映射（仅供初步参考，不构成等保测评结论）**：A/B ≈ 满足等保三级 Web 层面主要技术要求；C ≈ 二级水平且有关键缺口；D/E ≈ 低于等保二级基本要求。正式定级与测评须按 GB/T 22239-2019 / GB/T 28448-2019 由具备资质的测评机构执行。

## 六、评估作业规范

1. **授权前置**：评估前须取得目标系统所有者的书面授权，明确范围、时间窗口、强度上限。未授权扫描可能违反《网络安全法》并承担法律责任。
2. **探测强度约束**：自动化工具仅执行公开页面抓取、响应头读取、DNS 查询与少量公开路径 GET 探测；禁止注入、爆破、压力测试类动作。
3. **频率建议**：外部暴露面评估每月 1 次；重大变更（改版、上线、证书更换）后即时评估；等保测评每年 1 次，渗透测试每年至少 1 次。
4. **结果闭环**：按等级处置时限整改（见 3.3），高危项 7 日内闭环，复测通过后归档报告。
5. **报告要素**：目标信息、评估时间、评分与等级、逐项发现（含标准映射与证据）、整改建议、复测记录、评估人与授权编号。

## 七、局限性说明

1. 自动化评估基于**外部可见面**，无法覆盖源码层漏洞、内部网络、业务逻辑、运维配置等，结论存在固有盲区；
2. TLS 协议/套件探测结果受客户端本地 OpenSSL 版本限制（如本机 OpenSSL 3.x 默认不支持部分遗留套件协商，可能低估服务端遗留协议开放情况），关键结论建议以 `testssl.sh`、SSL Labs 交叉验证；
3. DNS 检测依赖系统解析器，DNSSEC 判定在解析器不支持 DNSSEC 时标记为「无法检测」；
4. 前端组件漏洞库为高频高危库的子集，不等同于完整 SCA；
5. 本清单及评分结果**不构成**等级保护测评、渗透测试或合规认证结论。
